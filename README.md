## RSA  
### Основные формулы
c = t^e mod N //шифрование  
t = c^d mod N //дешифрование

### Проводим алгоритм
p = 17
q = 19 
  
N = p * q = 17 * 19 = 323
f(N) = f(p * q) = (p-1)(q-1) = 16 * 18  = 288  

e - шифрующая экспонента или же открытый ключ, при чем НОД(f, e) = 1  
Подбираем e = 5  

d - ? Нужно найти такое d, чтобы d * e mod f(N) = 1 --> d * e + x * f = 1 // решаем с помощью уравнения Евклида  
d * 5 + x * 288 = 1.
d *  = -115, где x = 2.  
d = d * mod f(N) = -115 mod 288 = 173

c = t^5 mod 323  
t = c^173 mod 323

Зашифруем ОК = 7975 (ASCII)  
Так как N небольшое, шифруем поразрядно (как в методичке):
7 -> 7^5 mod 323 = 16807 mod 323 = 11
9 -> 9^5 mod 323 = 59049 mod 323 = 265
7 -> 7^5 mod 323 = 11
5 -> 5^5 mod 323 = 3125 mod 323 = 218

Шифротекст: 11 265 11 218

Расшифруем:
11^173 mod 323 = 7
265^173 mod 323 = 9
11^173 mod 323 = 7
218^173 mod 323 = 5
Получаем исходное сообщение: 7975 - ОК.

## Вопросы
1) - Открытый ключ: (e, N); Закрытый ключ (d, p, q, f)
2) - Почему : d * e + x * f = 1 соответствует d * e mod f
   - Потому что это уравнение Безу. Перенеся x * f вправо, получим d * e = 1 - x * f. Это значит, что при делении d * e на f остаток равен 1.
3) - Почему : e должно быть взаимно простым с f(N) - если они не будут взаимно простыми, то дешшифрация невозможна
